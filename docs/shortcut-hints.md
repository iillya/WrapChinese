# 快捷键提示显示修复（2026-10-16）

本轮覆盖 Wrap 2025.11.14 本地程序中发现的 94 条不同的上下文快捷键/鼠标提示，
并核对 6 条带 `Shortcut:` 的时间轴工具提示。正式词典新增 89 项：82 条缺失的
上下文提示、1 条播放提示和截图中的 6 个节点/参数词条；另修正 2 条旧译文中的
`SPACE` 标记，保留原始按键编码。词典共 2805 项。

## 显示方式

Wrap 的 Markdown 辅助绘制器使用 `QTextDocument::drawContents()` 将提示渲染到
透明 `QPixmap`，随后缓存使用。原有文字 Hook 无法覆盖这条图片显示路径。
本次增加由导出符号解析的文档绘制及两个 `QPainter::drawPixmap()` 显示 Hook，
没有使用固定地址；本地 Qt 5.15.3 的 8 个所需绘制导出均已验证。

宿主的文档和图片仍由原始 Qt 函数绘制英文。插件只为审核白名单中的完整提示行
及其明确的文字片段建立独立绘制配方；显示对象必须为
`Wrap::WContextHelpHintBase` 或其子控件，才可使用私有中文图片。一般 QWidget、
离屏图片、工程数据及用户文档不会因复用同一图片而变成中文。

`*LMB*`、`*SHIFT*` 等按键标记的顺序必须与原文一致。图片和按键内容不参与
替换，仅在克隆文档中替换说明文字。中文图片上限为 32 MiB，配方上限为 512 项；
淘汰中文图片不影响宿主仍持有的英文缓存再次显示中文。所有缓存仅在 GUI 线程
使用；语言关闭时显示路径立即透传。新增 IAT 槽位有恢复记录，退出清理幂等。

本轮同时删除通过省略前缀猜词的旧逻辑；只有可以读取完整 QLabel 原文时才恢复
完整译文。节点参数标题的富文本替换限定在加粗的类型部分，后面的节点实例名
继续使用宿主原文。未向宿主控件、Model、节点或工程写入中文。

## 验证

`tests\run.bat --display-only` 使用 Wrap 2025.11.14 随附的 Qt 5.15.3 运行时，
通过 Qt 的 `offscreen` 平台执行，不控制桌面，也不启动 Wrap。

- 94 条完整提示逐条比较插件输出与独立的中文原生渲染。
- 97 种分段 Markdown 说明文字逐条比较。
- 整组 14 行笔刷提示、图片按键资源和 1.5 倍 DPR。
- 关闭期间生成缓存后重新开启；反复中英切换只重绘，不修改英文源缓存。
- 超过中文图片预算后复用早期宿主缓存。
- 源文档 HTML、revision、contentsChanged 信号和原始图片像素保持不变。
- 普通 QWidget、混合业务文档和离屏图片导出保持原文。
- 新增 Hook 的 IAT 槽恢复和重复清理。
- 原有控件尺寸、富文本、Model 数据与显示边界回归。

本轮未启动实际 Wrap 界面、未安装补丁，也未执行真实安装/卸载；这是用户要求
不控制电脑的边界。工程关联注册表测试与本次显示修复无关，使用 `--display-only`
跳过；本轮最初尝试默认测试时其隔离注册表根创建被沙箱拒绝。

静态审核入口为 `scripts/audit_shortcut_hints.py <Wrap.exe>`；输出在 `build/`。
审核来源、文件偏移、宿主和输入/输出词典哈希保存在
`translations/review/shortcut_hints_20261016_zh.review.json`。提取不运行宿主代码。
新增其他版本时应重新扫描并审核，不能将本轮有限词条集合等同于所有未来版本
或动态插件内容都已验证。

最终构建和载荷哈希以 `build/inno/manifest.json` 为准。
