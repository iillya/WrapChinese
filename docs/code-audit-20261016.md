# WrapChinese 1.0.2 代码审核

审核覆盖运行时 Hook、翻译查询、绘制度量、快捷键缓存、菜单与配置、启动器、
安装器支持代码、词典和构建/采集脚本。沿用《Qt 纯显示层汉化统一规范》1.8。
本轮没有启动 Wrap、控制桌面、安装补丁或改动用户工程。

## 修正的缺陷

| 问题 | 修正 |
|---|---|
| 所有 `%1` 词条都自动成为任意字符串模板 | 仅允许 `numeric_template_sources.h` 中 16 条数字提示；整串、大小写、空格严格匹配，不接受名称、路径、空值、指数或任意通配；歧义保留英文 |
| 动态模板先于归一化词条，且可能进入无控件上下文的测量 | 精确/归一化优先；通用测量不启用数字模板 |
| 普通标签绘制一段文字时可能重复整个标签 | 仅在确实省略的普通标签上读取完整原文，其余片段保持独立 |
| 输入框及其缓存绘制可能进入汉化 | 排除行编辑器、文本编辑器及 viewport、数字输入、快捷键输入和可编辑下拉框的绘制作用域 |
| 字典先转为无序表，再构建归一化表，丢失覆盖次序 | 按稳定文件/词条顺序建立 QString 索引，后输入覆盖；冲突在初始化记录到主动诊断 |
| 全角拉丁字母被误判为已有中文 | 统一全角 ASCII、下划线、零宽/软连字符、引号、破折号和组合音标；Python 词典审核采用同一归一化规则 |
| Hook 恢复不完整，原 Style/Palette 记录没有实际使用 | 统一关闭流程恢复自有 IAT、默认委托、可重建样式、Palette、菜单和缓存；宿主后来更换的样式/委托保持原样；DLL 仍固定到进程结束 |
| Qt5/x64 检查不能识别 MSVC 与 MinGW ABI | 启动器与安装器共用只读 PE 导出检查，提前排除不匹配的 ABI；运行时函数地址还须位于可执行内存 |
| 快捷键可能被宿主的 QShortcut 提前处理 | 在 ShortcutOverride 阶段声明插件快捷键，实际动作仍仅在按下时执行 |
| 插件链接按显示文字染色、晚出现 Help 时位置不稳定 | 按插件 QAction 身份绘制，禁用态用宿主颜色；固定 objectName 并幂等调整位置；关闭时恢复鼠标跟踪 |
| 采集主动触发菜单回调及 fetchMore | 仅读取已创建菜单和模型行，不触发宿主信号、不加载工程内容；因此尚未展开的懒加载项需由用户正常打开后再采集 |

数字白名单有意缩小旧行为：带文件名、节点名等任意字符串的动态提示可能继续
显示英文。原始 `%1` 词条仍保留在词典中；没有为了覆盖率扩大匹配范围。

## 清理与性能

- 删除通用字符串模板的递归回溯、前缀为空的兜底、未使用的 Template 结构、
  重复的 PE 架构/Qt 版本检查、无效审词统计和多次强制全界面重绘。
- 节点自动创建、菜单模拟操作、自动采集/退出及完整控件清单移至开发编译分支，
  普通发行 DLL 不包含这些入口。开发版输出到 `build/dev/out`，不进入安装器。
- 默认关闭每两秒的周期补扫，保留旧版兼容实现；改为 Show/Polish 等事件合并
  请求，限制扫描频率。关闭语言显示时仍正常观察新控件。
- 绘制/度量导入表按模块批量遍历，并按内存区域验证，不逐个导入槽查询内存。
- 字典直接使用 QString 哈希，去除热路径 UTF-8 往返；命中和未命中仍使用线程
  本地有界缓存。超过 4096 字符的输入在哈希前返回，不进入缓存。
- 普通富文本标签复用布局文档；源文、译文、字体、宽度、方向、对齐和换行
  改变时重建。缓存按估算 KiB 计费，总额度 512 KiB，过期对象有界淘汰。
- 快捷键图片按 cacheKey 索引，先排除无关图片，再检查帮助控件；中文位图仍为
  32 MiB 上限、配方最多 512 份。分配失败保留原英文图片。

性能对照采用审核前工作区源码快照与修改版、相同编译选项和 Qt 5.15.3，
交替运行三组，取中位数：

| 无界面基准 | 审核前工作区 | 审核后工作区 | 耗时降低 |
|---|---:|---:|---:|
| 30 万次、900 种词条查询 | 99.93 ms | 68.02 ms | 31.9% |
| 相同富文本标签绘制 1000 次 | 25.13 ms | 12.77 ms | 49.2% |

这是指定代码路径的微基准，不代表 Wrap 整体帧率或 CPU 占用的实测变化。
原始数据在 `build/audit-performance.json`，基准代码为
`tests/audit_performance.cpp`。审核前源码在本地 `build/audit-before/source`，
不属于发行负载。

## 验证与边界

- `tests/run.bat --display-only`：原有显示层、宿主数据保留、导出隔离、设置与
  采集保全、94 条完整提示及 97 类分段提示、DPI 100/125/150/200%、宿主样式表。
- 新增 `audit_runtime.cpp`：覆盖覆盖次序、模板边界、输入保护、标签片段与布局
  缓存、晚到菜单、关闭语言时挂载、只读采集、地址/ABI检查以及重复关闭恢复。
- `tests/run_launcher.bat`：仅运行测试程序自身的隐藏子进程，验证模块地址解析、
  关闭等待与超时，没有启动或附加 Wrap。
- 普通发行版和开发版分别编译；安装器只包含 Hook、启动器及词典，核对负载和
  安装包 SHA-256，并检查发行二进制不含开发自动化入口。

工程关联事务代码本轮完成静态审查，未改动事务逻辑；受当前环境注册表写权限
限制，本轮没有重新运行关联写入/回滚/卸载测试，也没有执行安装器。
真实 Wrap 界面、显卡驱动及其他用户的按钮空白故障仍需对方现场验证，不能以
上述无界面测试替代。
